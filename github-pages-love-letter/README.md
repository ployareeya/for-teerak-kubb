# จดหมายถึงเธอ 💌

เว็บไซต์จดหมายแบบไฟล์เดียวสำหรับ GitHub Pages

## เปิดดูในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ หรือเปิดเพื่อแก้ไขด้วย VS Code รูปทั้ง 6 ใบฝังอยู่ในไฟล์แล้ว

## เผยแพร่บน GitHub Pages

อัปโหลด `index.html` ไปที่รากของ repository จากนั้นตั้งค่า Pages ให้เผยแพร่จากสาขา `main` และโฟลเดอร์ `/ (root)`

ข้อความและรูปใน repository และเว็บไซต์จะมองเห็นได้สาธารณะเมื่อเผยแพร่
